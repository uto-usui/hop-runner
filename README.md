# Hop Runner

自動で横スクロールするオートランナー。操作は **ジャンプだけ**。
押すタイミングと長さで障害物（恐竜ゲーム風）を跳び越えて、走った距離を競う。

## 操作

- **SPACE / ↑ / W / 画面タップ** … ジャンプ
- **長押し** … 高く・長く飛ぶ（ちょん押しは小さくホップ）
- ゲームオーバー後はもう一度押すとリトライ

## 開発

```sh
pnpm install
pnpm dev      # 開発サーバー（http://localhost:5173）
pnpm build    # 型チェック + 本番ビルド（dist/）
pnpm preview  # ビルド結果をローカル確認
```

## 構成

```
src/
  main.ts     エントリポイント（canvas を取得して Game を起動）
  game.ts     ゲームループ・状態管理・当たり判定・描画
  player.ts   プレイヤーの物理（可変ジャンプ）
  world.ts    地面スクロールと障害物の生成・移動
  input.ts    ジャンプ入力（キー / マウス / タッチを統一）
  config.ts   チューニング値（重力・ジャンプ・速度・障害物）
```

手触りの調整は基本 `src/config.ts` の数字だけで完結する。
まず `PHYSICS`（ジャンプの気持ちよさ）と `SPEED`（難易度の上がり方）をいじるのがおすすめ。
