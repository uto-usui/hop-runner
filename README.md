# Hop Runner

**▶ 遊ぶ: https://uto-usui.github.io/hop-runner/**

自動で横スクロールするオートランナー。操作は **ジャンプだけ**。
押すタイミングと長さで障害物（恐竜ゲーム風）を跳び越えて、走った距離とスコアを競う。
障害物すれすれを攻めるほど（ニアミス）コンボ倍率が伸びて高得点になる。

## 操作

- **SPACE / ↑ / W / 画面タップ** … ジャンプ
- **長押し** … 高く・長く飛ぶ（ちょん押しは小さくホップ）
- **M** … サウンドのミュート切替
- **H** … 調整パネル（Tweakpane）の開閉
- ゲームオーバー後はもう一度押すとリトライ

## 遊びの要素

- **可変ジャンプ**: 押す長さで高さ・距離が変わる。地形が「長押し必須の低く長い壁」「素早い高ジャンプが要る高い壁」「連続でリズム」などを要求する（距離で難易度カーブ、必ず越えられる範囲に制限）。
- **ニアミス & コンボ**: 障害物すれすれを越えるとボーナス＋倍率アップ。攻めるほど稼げる。
- **収集オーブ**: 空中の金オーブを取ると加点。高さ精度が意味を持つ（取れなくても死なない）。
- **マイルストーン**: 一定距離ごとに祝祭演出。
- **自己ベスト距離マーカー**: 地面に自己ベスト地点のラインが流れ、「あと少し」を可視化。
- **デイリーシード**: 当日固定の地形で競える（調整パネルの「オーブ / シード」で切替、次のランから反映）。

## 手触り（juice）

squash & stretch、着地/ジャンプの土埃、死亡破片、画面シェイク（trauma 方式）、死亡ヒットストップ、
速度連動のトレイル/ビネット/カメラ引き、多層パララックス背景、距離で移ろう昼夜・バイオームの配色、
WebAudio による手続き生成サウンド（ジャンプ/着地/死亡/ニアミス/取得/マイルストーン）。

酔い・好みに応じて、調整パネルの `シェイク強=0` や `ミュート` で演出を弱められる。

## 開発

```sh
pnpm install
pnpm dev      # 開発サーバー（http://localhost:5173）
pnpm build    # 型チェック + 本番ビルド（dist/）
pnpm preview  # ビルド結果をローカル確認
pnpm typecheck # 型チェックのみ（コミット前に lefthook が自動実行）
```

開発時は `window.game` でゲームインスタンスにアクセスでき、手動チューニングやデバッグに使える。

## 構成

```
src/
  main.ts          エントリポイント（Game 起動・Tweakpane・dev フック）
  game.ts          ゲームループ・状態管理・当たり判定・採点配線・全描画
  player.ts        プレイヤーの物理（可変ジャンプ）と squash & stretch
  world.ts         地面スクロールと障害物（パターン）の生成・移動
  patterns.ts      障害物パターン生成＋クリア可能性の保証
  score.ts         スコア・コンボ・ニアミス・浮遊加点・マイルストーン
  theme.ts         昼夜×バイオームのパレット補間
  collectibles.ts  収集オーブの生成・移動・取得
  rng.ts           シード可能な擬似乱数（デイリーシードの土台）
  input.ts         ジャンプ入力（キー / マウス / タッチを統一）
  config.ts        全チューニング値（Tweakpane と直結）
  tweak.ts         実行中に config を生調整する Tweakpane パネル
  juice/
    camera.ts      画面シェイク（trauma 方式）＋カメラ scale
    particles.ts   軽量パーティクル（土埃・破片・スピードライン）
    audio.ts       WebAudio 手続き生成サウンド
```

手触り・難易度・演出の調整は基本 `src/config.ts` の数字だけで完結し、`H` の Tweakpane から実行中にも触れる。
まず `PHYSICS`（ジャンプの気持ちよさ）と `SPEED`（難易度の上がり方）をいじるのがおすすめ。

### ブランディング（OGP / favicon）

シェア用の OGP カード・favicon・PWA アイコンは `branding/` の SVG が唯一のソース。
`branding/icon.svg`（アプリアイコン）/ `branding/og.svg`（1200×630）を編集したら、`sh branding/build-assets.sh`
（要 `rsvg-convert` + `magick`）で `public/` の PNG・ICO・`og.png` を再生成する。配色・キャラ・障害物・オーブは
実ゲームの描画に揃えてある。メタタグは `index.html` の `<head>` 参照。

## 設計メモ

- 操作は **ジャンプ1入力のみ**（`input.ts` は不変）。演出・採点・地形を足しても操作のシンプルさは変えない。
- squash/stretch・トレイル・shake・zoom は **描画のみ**で、当たり判定（AABB）は元サイズ・実座標で計算する。
- 障害物・オーブは現在の `PHYSICS`/`SPEED` から算出した **クリア可能エンベロープ内**に収め、理不尽な配置を出さない。
- 描画順: 背景（camera 外）→ camera(shake/zoom) 内で地面・障害物・オーブ・プレイヤー・パーティクル → ビネット/フラッシュ/HUD（camera 外）。
